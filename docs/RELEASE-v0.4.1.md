# v0.4.1 更新说明

发布日期：2026-09-24 · 适用平台：Windows x64（单文件 exe，目标电脑无需安装 .NET）

本次是**缺陷修复版本**：修好「在设置里选了 Train Sim World 6 数据源，保存后又变回 X-Plane 12，iPad 上一直显示数据超时」。没有新增功能，也没有改动前端资源（网页不需要清缓存）。

---

## 1. 缺陷一：保存设置会删掉 TSW 数据源的四个键

### 表现

| 步骤 | v0.4.0 的实际结果 |
| --- | --- |
| 设置窗口 → 数据源改选「Train Sim World 6（本机 HTTP API）」 | 正常，下拉框可选、TSW 相关字段会启用 |
| 点「测试连接」 | **正常**，能读到坐标、速度与车次——所以很难怀疑是配置问题 |
| 点「保存」 | 提示保存成功（或“内容一致”），可能生成 `.bak` 备份 |
| 再打开设置窗口 | 数据源又回到「X-Plane 12（UDP DATA 包，默认）」 |
| iPad 网页 | 顶部一直显示「接收 X-Plane 12 数据」，地图显示「数据超时」 |

### 原因

配置文件的写回集中在 `ConfigStore.BuildRoot()`：它先按下标显式写出所有已知字段，再把文件里**程序不认识**的键原样搬回来（这样用户手写的内容不会丢）。而“原样搬回来”的循环是：

```csharp
if (known.Contains(item.Key)) continue;   // 认识的键跳过：以为前面已经写过了
```

`TelemetrySource`、`TswApiUrl`、`TswApiKeyPath`、`TswPollHz` 这四个键在加入 TSW 数据源时被登记进了 `KnownKeys`，但**忘了在 `BuildRoot()` 里写出**。于是它们既不在“认识的键”那段输出里，又被“不认识的键”那段跳过——每次保存都被静默删除，下次读取只剩默认值 `xp`。

「测试连接」用的是设置窗口内存里的值，不经过配置文件，所以测试永远是好的：**只有落盘这一环断了**。

### 修复

- `ConfigStore.BuildRoot()` 补上这四个键，并在代码注释里写明约束：*凡是 `KnownKeys` 里的键，都必须在这里写出*。
- 自检新增两条断言，专门盯住这一类错误：
  - **每个已知键都会写进文件**：逐条比对 `KnownKeys` 是否都出现在保存后的文件里（本次 23 个键全部通过）；
  - **TSW 数据源保存后能读回**：把 `TelemetrySource=tsw`、`TswPollHz=7`、密钥路径写入后再读回校验。

## 2. 缺陷二：切换数据源不提示重启

### 表现

即使配置文件是对的，保存后服务仍按旧数据源运行，iPad 上一直看不到列车；必须自己想到去托盘菜单点「重新加载配置（重启服务）」才行，而窗口全程没有提示。

### 原因

采集器是在 `BridgeService.RunAsync()` 启动时**一次性选定**的（要么监听 UDP，要么轮询 TSW API），运行时没有热切换。而设置窗口只在**端口**变化时才弹「需要重启服务，现在重启吗？」，`RestartRequested` 也只由端口改动设置；数据源变化只是被记成“待重启”，既不询问也不自动重启。

### 修复

- 数据源变化（含 TSW API 地址、密钥路径变化）与端口变化同等对待：保存时弹出重启询问，提示语按原因区分（「端口改动」/「数据源改动」/「端口和数据源改动」）。
- 托盘待重启提示改为「配置已保存 · 端口或数据源改动待重启服务生效（托盘菜单 → 重新加载配置）」，不再只提到端口。

## 3. 升级步骤（需要手动做一次）

1. 用新的 exe 替换旧文件。
2. 托盘 → **设置… → 地图跟随哪个模拟器**，重新选一次「Train Sim World 6（本机 HTTP API）」→ 保存。
   v0.4.0 及更早版本已经把旧配置里的这四个键删掉了，需要写回一次；之后版本不会再丢。
3. 保存时选「**是**」立即重启服务（不重启的话托盘会一直提示“待重启”）。
4. iPad 刷新页面即可，前端资源没有变化，不用清站点数据。

> 如果你在设置里手动指定过 TSW API 地址或密钥路径，第 2 步请一并填回——那些值同样在旧版本的保存过程中被删掉了，程序当前会退回默认值（`http://127.0.0.1:31270` 与自动查找 `CommAPIKey.txt`）。

## 已知限制

- 仅用于模拟飞行 / 模拟驾驶娱乐，**不得用于真实导航或真实铁路调度**。
- exe 未做代码签名，Windows SmartScreen 会提示。
- 服务监听 `0.0.0.0` 且没有登录鉴权，只适合可信的家庭/训练局域网，不要做端口转发。
- TSW6 需要 PC 版、Steam 启动项加 `-HTTPAPI`，且必须与 exe 在同一台电脑上运行（API 只监听回环地址）。
