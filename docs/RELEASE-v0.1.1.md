# v0.1.1 修复说明

发布日期：2026-09-11 · 适用平台：Windows x64（单文件 exe，目标电脑无需安装 .NET）
下载文件：`XPlaneEfbBridge-v0.1.1-win-x64.exe`

这一版只修问题、不加功能，重点是把上一版里“明明配置了却看不到数据”和“点一下就崩”的两处坑填掉。

## 1. V/S 固定显示 -999

- **原因**：X-Plane 用 `-999` 表示“这个槽位没有数据”，而 Data Output 行 4（Mach, VVI, g-load）的 VVI 列可能整段飞行都停在这个哨兵值上。旧版把它当成正常读数直接显示。
- **修复**：`-999`（以及任何 |值| > 20000 的读数）一律判为无效，改用高度流（行 20，地图本来就需要它）推算垂直速度：6 秒滑窗最小二乘斜率 + 指数平滑，高度跳变（传送、重置）会清空窗口重新收敛，平飞时归零；能读到真实 VVI 时仍优先用模拟器的值。
- **顺带修掉**：g-load 原先取的是“侧向过载”槽位，现在按官方字段顺序取“法向过载”，与 g-load 列一致。

## 2. 地面滑行数据看不到 / 选目录时 exe 崩溃

- **点“浏览…”导致 exe 卡死退出**：旧版用的是 Windows 系统文件夹对话框，它会加载机器上安装的全部 Shell 扩展（网盘、下载器、文件管理器…），其中一个有缺陷就会把宿主进程一起带走。新版换成程序内置的文件夹选择器（纯 WinForms，不经过 Shell），并给整个流程加了异常保护；实在不行还可以把路径直接粘贴进输入框。
- **手动粘贴路径也不生效**：旧版只在服务启动时读一次 X-Plane 目录，之后改配置不会生效（而端口类配置才提示重启，用户无从得知）。新版把目录改成“每次查询都重新解析”，保存后立即在后台重建索引，无需重启。
- **首次索引会卡住界面**：默认机场包 apt.dat 可达上百 MB，旧版会在第一个请求里同步解析。新版改为后台建立，接口先返回 `building` 状态，iPad 显示“正在建立机场索引…”，完成后自动绘制。
- **路径容错**：选到上一级、`X-Plane 12` 本身、`Resources`、甚至 `apt.dat` 文件都会被自动纠正到安装根目录；`Custom Scenery` 内的机场包（`Earth nav data\apt.dat` 与包根目录的 `apt.dat`）都会索引，后索引的覆盖默认数据。
- **可诊断**：新增 `GET /api/ground/status`（`configured / ready / building / airports / files / bytes / error`），设置窗口里选完目录会立刻显示“找到 N 个 apt.dat、共多少 MB”，网页端在未配置、索引中、附近无机场三种情况下分别给出提示。

## 2b. 地面图层“看不到变化”

第一版地面图层的数据链路是通的，但用户几乎发现不了它：**OpenStreetMap 底图本身就会画淡灰色的机坪/滑行道，还带自己的一套机位与滑行道文字**，而我们的颜色与它太接近；更关键的是，**开关打开时如果缩放还不够大，旧版什么都不会发生**，看起来就像功能坏了。

- 重新设计配色：蓝灰铺面 + 亮蓝描边、亮黄色地面标线、深色外框跑道的白虚线中线、黄点机位，标签换成琥珀色（机位）与青色（滑行道标牌）并放大到 13px 带描边阴影。
- 数据加载成功时弹出一次「KSEA 地面数据已加载：跑道 2 · 铺面 18 · 滑行道 21 · 标牌 40 · 机位 96」，抽屉里新增「地面图层」一行常驻显示当前机场与要素数量。
- 缩放不足时点开关会明确提示「地面图层要缩放到 15 级以上才会显示（当前 12）」，而不是静默无反应。
- 说明：改了 apt.dat（装新机场包、改地景）后，重新保存一次设置或重启 exe 才会重新索引。

## 3. 新增诊断工具

```powershell
.\XPlaneEfbBridge.exe --dump-udp "%LOCALAPPDATA%\XPlaneEfbBridge\bridge-config.json" 20
```

采样 20 秒原始 UDP，逐行列出每个数据行的 8 个槽位（最小值/最大值/最后值/有效样本数），恒为 -999 的槽位直接标注为“X-Plane 表示无数据”，报告同时写入配置目录的 `udp-dump.txt`。以后遇到“某个数值不对”可以直接拿这份报告定位。

## 4. 升级方式

直接替换 exe 即可：配置文件、SimBrief 历史计划、机场索引缓存都在 `%LOCALAPPDATA%\XPlaneEfbBridge\`，不会被覆盖。若更改过 X-Plane 目录，升级后第一次打开地面图层会重新建立一次索引（之后走缓存）。

自检：`XPlaneEfbBridge.exe --config-selftest <空目录>`，共 85 项（在无凭据服务的受限环境下仅 DPAPI 加密那一项会失败）。
