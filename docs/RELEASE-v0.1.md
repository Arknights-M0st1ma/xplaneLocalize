# v0.1 发布说明

发布日期：2026-09-11 · 适用平台：Windows x64（单文件 exe，目标电脑无需安装 .NET）

## 主要功能

- **局域网内接收 X-Plane 12 UDP 广播**：默认监听 49000（可配多个候选端口与来源 IP 白名单），解析 Data Output 行 3/4/17/20（IAS/TAS/GS、Mach/VVI/G、俯仰/滚转/真磁航向、经纬度与 MSL/AGL 高度），分包状态合并、缺行容错。
- **WebSocket 实时转发**：网页与 WS 同源（同一个 exe、同一个端口），无需 CORS；自动重连、3 秒数据超时提示、诊断面板。
- **iPad 网页端 EFB**：响应式、安全区适配、触摸友好；OpenStreetMap 为主力底图，可另配授权的自定义 XYZ 底图。
- **飞机位置、航向、高度、速度与轨迹**：仪表、飞机图标（航向向上时始终朝上）、2,000 点轨迹（外发光+描边+亮色主线+起点标记）。
- **航向向上（可旋转地图）**：容器级 CSS 旋转实现，双指缩放/点按坐标正确，指针与旋转中心随地图区域变化自动修正。
- **SimBrief 航路叠加（可选）**：只在你点击时请求一次、绝不后台轮询；本地归档历史计划（最多 12 份）可随时切回；EFB 内可浏览完整 OFP（居中子窗口）；支持系统/直连/自定义代理（可带认证，密码 DPAPI 加密保存）。
- **天气 overlay（可选，OpenWeatherMap）**：云/降水/风/温度/气压，图层图标位于地图左侧，默认不透明度 0.85 且可调；API Key 只存在电脑上，由桥接器代理取瓦片（含缓存与限流），无数据时给出明确提示并自动署名。
- **航班状态毛玻璃卡片**：航班号、起降与计划时刻（UTC）、航路时间、进度、剩余距离/时间、ETA（与计划对比）、地速/高度/航向/状态/更新时间；可拖动、折叠、隐藏（左侧图标恢复）；地速无效或 <30 kt 时显示“未知”。
- **机场地面图层（可选，本机 apt.dat）**：缩放 ≥ 阈值（默认 15，可配）才解析并绘制跑道（含中线）、滑行道/机坪铺面、地面标线、ATC 滑行路线；再放大一级显示机位号与滑行道标牌文字；只读本机文件、不随 exe 分发。
- **航司标识**：按呼号 ICAO 三字码显示彩色徽章（内置 90 家航司名称/IATA 表，离线可用）；如你拥有授权来源，可配置 logo 地址模板并自动回退。
- **可视化设置界面**：托盘 → 设置…，分组为 连接 / 地图 / SimBrief / 天气 / 高级；配置原子写入、保存前备份、未知键保留、外部修改冲突提示，端口类改动会询问是否立即重启；含开机自启、诊断与“测试连接”。
- **夜间模式**：只对底图生效的深色滤镜，航迹/航路/天气/卡片/控件不受影响。

## 安装与使用

1. 把 `XPlaneEfbBridge-v0.1-win-x64.exe` 放到固定目录并双击运行（无主窗口，常驻系统托盘）。
2. 首次运行会在 `%LOCALAPPDATA%\XPlaneEfbBridge\bridge-config.json` 生成配置，并弹出 iPad 访问地址。
3. Windows 防火墙弹窗只允许“专用网络”。
4. X-Plane 12 → Settings → Data Output，勾选行 3、4、17、20 的 **Network via UDP**，目标 IP 填运行 exe 的电脑，端口与配置里的 UDP 端口一致（默认 49000）。
5. iPad 与电脑连同一 Wi-Fi，浏览器打开 `http://电脑IP:8080`。

托盘菜单：设置… / 在本机打开 EFB / 显示访问说明 / 高级（记事本打开配置、打开配置文件夹）/ 重新加载配置（重启服务）/ 开机自动启动 / 退出。

## 已知限制

- 仅用于飞行模拟，**不得用于真实导航**。
- 局域网服务无登录鉴权，只适合可信家庭/训练网络；不要做端口转发。
- OSM 与天气/航司 logo（若配置）需要 iPad 能访问互联网；飞机数据链路完全在局域网内。
- 地面数据依赖本机 X-Plane 安装（apt.dat）：不还原滑行道纹理与标牌朝向，第三方地景质量参差时可能缺件。
- 天气 overlay 的“降水”等图层在无降水的区域本身就是透明的，界面会提示“当前区域没有数据”。
