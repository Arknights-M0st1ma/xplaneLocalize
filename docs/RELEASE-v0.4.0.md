# v0.4.0 更新说明

发布日期：2026-09-23 · 适用平台：Windows x64（单文件 exe，目标电脑无需安装 .NET）

本次把界面从「一个地图页 + 右侧设置抽屉」改成 **左侧导航栏 + 四个页面**，并新增了带书签的 PDF 手册阅读器和详细的飞行计划页。

---

## 1. 新的左侧导航栏

```
┌────┬──────────────────────────────────────────┐
│EFB │  ← 收缩：只有 logo 和四个图标             │
│ ▸  │                                          │
│    │                                          │
├────┼──────────────────────────────────────────┤
│EFB │ 地图页的面板                              │
│地图 │ 底图 / 显示 / 航迹保留      ← 展开：本页的功能界面
│计划 │                                          │
│手册 │                                          │
│设置 │                                          │
└────┴──────────────────────────────────────────┘
```

| 行为 | 说明 |
| --- | --- |
| 收缩 | 68px：EFB 标识 + 四个页面图标，收起时地图拿回全部宽度 |
| 展开 | 340px：页面图标带文字，下方是该页的功能面板 |
| 竖屏 / 手机（≤900px） | 展开态变成覆盖式浮层（带遮罩），选完页面自动收起，避免压住内容 |
| 记忆 | 上次打开的页面与展开状态都会记住 |
| 地图页 ☰ | 与侧边栏左侧的箭头同一个开关 |

四个页面分别是：

1. **地图页**：原来的移动地图，功能不变；左侧面板放「底图 / 显示 / 航迹保留」。
2. **计划页**：SimBrief 计划的详细视图（见下）。
3. **手册页**：新的 PDF 阅读器（见下）。
4. **设置页**：原来右侧栏的内容拆成两半——需要边看地图边改的（图层、显示）留在地图页，其余（电脑端设置指引、两个快捷开关）在侧栏，主区显示数据链路、手册库、版本等状态。

## 2. 手册页：带书签导航的 PDF 阅读器

PDF 放在**电脑上**（iPad 看不到电脑的文件系统），所以由桥接器列目录、按字节范围推流。

### 电脑端

- 设置窗口 → **地图 → 手册文件夹**：选择一个目录（子文件夹也会被递归列出，最多 600 个 PDF）。
- 新接口：
  - `GET /api/manuals` → 文件清单（相对路径、名称、大小、修改时间）
  - `GET /api/manuals/file?path=…` → PDF 本体，支持 `Range` 请求（大文件从第 1 页开始显示，不必等整本下载完）
- 安全边界：只允许配置目录内的 `.pdf`；`..`、绝对路径、盘符路径、符号链接跳出、非 PDF 一律 404。

### iPad 端阅读器（内置 PDF.js，[vendor/pdfjs](vendor/pdfjs) 本地打包，不联外网）

| 功能 | 说明 |
| --- | --- |
| **书签 / 大纲** | 侧栏树状导航，支持任意层级，点击跳页；没有大纲的文档会明确说明 |
| 页面缩略图 | 侧栏网格，懒加载渲染，点击跳页 |
| 连续滚动 | 按需渲染可见页（IntersectionObserver），几百页的手册也不卡 |
| 缩放 | 放大 / 缩小 / 适合宽度 / 整页 / 当前百分比显示 |
| 旋转 | 每次 90° |
| 文本层 | 可选中复制（PDF.js TextLayer） |
| 全文搜索 | 输入即搜（500ms 防抖），显示「第 n/N 处匹配 · 第 x 页」，↑/↓ 在命中之间跳转，命中文本高亮 |
| 页码跳转 | 直接输入页码，回车即跳 |
| 记住位置 | 每本手册记住上次读到第几页，下次打开自动跳回 |
| 文件列表 | 名称过滤、目录/大小显示、当前文件高亮、一键重新扫描 |
| 下载 | 直接从电脑端取回原文件 |
| 键盘 | ←/→ 翻页，+/- 缩放，Enter / Shift+Enter 在搜索结果间跳转 |
| 夜间模式 | 页面画布自动反色（不改变原件） |
| 中文手册 | 打包了 cmaps 与标准字体，CJK 文本不会变成方块 |

## 3. 计划页：SimBrief 计划的详细视图

左侧面板是「计划选择 / 获取·刷新 / 查看完整 OFP / 摘要」，主区是明细：

- 顶栏：航段、呼号、机型与注册号、航路字符串；计划离港 / 预计到达 / 计划到达 / 航路时间。
- 概览卡：航路距离、巡航高度（FL）、巡航马赫与 TAS、航点数与航段数、备降机场、大圆距离。
- **航段表**：序号、航点、航路（via）、高度（FL）、本段距离、累计距离与**按航段分摊的预计时刻**、经纬度。起降机场自动去重、加粗。
- **载重与燃油**：乘客、业载、ZFW/TOW/LW（含各上限）、起飞油量、航段耗油、滑行、备份油、备降油、最终储备；单位跟随 SimBrief 报告（kg/lb）。
- **中英双语标注**：载重与燃油、巡航、备降的每一行都是「中文 + English」（如 零油重量 / ZFW (Zero Fuel Weight)），卡片标题与概览卡同样带英文。
- **上限改为悬浮提示**：鼠标停在（或手指点在）零油重量、起飞重量、着陆重量上时，浮出当前机型的 **MZFW / MTOW / MLW** 与机型名，行内不再挤一行小字；键盘聚焦同样能看到。
- 巡航与备降：成本指数、空中距离、计划生成时间、每个备降机场的名称与跑道。
- 解析层新增 `units / weight / fuel / cruise` 字段（Node 与 C# 双端，均有测试），并**按真实 json=v2 字段名**读取。

## 4. 其他

- **修复**：计划页的「载重与燃油」整块是空的/只有 `—`。原因是解析层用了 `weights.zfw / tow / ldw / mtow / mlw / mzfw` 这些**猜的字段名**，而真实的 json=v2 OFP 用的是 `est_zfw / est_tow / est_ldw`（计划重量）与 `max_zfw / max_tow / max_ldw`（机型上限），单位在 `params.units` 而不是重量块里。现在按真实字段读取，并保留短名作为兼容回退；测试夹具也换成了真实结构（原来的夹具是自己编的字段名，所以测试一直是「通过」却测不到真实数据）。
- **修复**：手册页的「大纲」「缩略图」按钮点开后侧栏是空白的。两个原因：① `updateSideVisibility()` 只会给容器**加** `hidden` 类、从不移除，所以从缩略图切回大纲（或反之）后容器仍是 `display:none`；② 缩略图的 IntersectionObserver 以**当时还隐藏着的** `#pdfThumbs` 作为 root，永远不会触发，缩略图因此从未渲染。现在改为对称的 `toggle()`，并且只在面板真正显示时才建立（以视口为 root 的）观察器。
- 前端资源版本 `v27 → v28`；`sw.js` 应用壳加入 `pages.js`、`manual.js`、PDF.js 运行时（cmaps 按需缓存）。
- **修复**：开发服务器与 exe 的 MIME 表缺少 `.mjs`，ES 模块会因 MIME 检查失败而整页脚本不执行（表现为页面像没加载完）。现在 `.mjs` 返回 `text/javascript`。
- **修复**：阅读器切换缩放/旋转后只隐藏画布不重绘，页面会空白；现在会按新尺寸重新渲染。
- **修复**：搜索框的防抖回调收到的是 Event 而不是字符串，触发 `value.trim is not a function`。
- **改进**：启动失败不再静默，会在控制台留下具体错误（此前只弹一句提示）。
- 版本号升到 `0.4.0`（package.json / csproj）。

## 升级方式

替换 exe；配置、计划历史与航迹都在 `%LOCALAPPDATA%\XPlaneEfbBridge\`。
第一次使用手册页：电脑端托盘 → 设置… → 地图 → **手册文件夹** → 选择目录 → 保存并重启服务。
iPad 端前端资源版本升到 `v28`，刷新一次页面即可。
